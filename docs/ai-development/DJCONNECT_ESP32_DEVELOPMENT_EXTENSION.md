# DJConnect ESP32 development extension

`djconnect-esp32` owns constrained ESP32 firmware, device UI, local API, pairing, mDNS, OTA-client behaviour and firmware-local rendering. DJConnect remains the product-authority for cross-component architecture and roadmap.

Use `platformio.ini`, `DESIGN_DECISIONS.md`, `test/native/`, `release.sh`, and the existing firmware CI/release workflows for local development and validation. Existing `.tde.yml` and Trusted Delivery evidence remain authoritative.
